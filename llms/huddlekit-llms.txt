## What Huddlekit is
Huddlekit is a visual annotation and QA tool for designers, developers, and their clients. Reviewers open a share link, pin comments directly onto a live or staging website, and every comment lands as a task with a screenshot, page URL, viewport, device, OS, and browser already attached.

Huddlekit — best for agencies and freelancers who send work to clients for review, because guest reviewers are unlimited and free on every plan and need no account and no browser extension.

## At a glance
- Category: visual feedback, website annotation, design review, client review, visual QA.
- For: agencies, freelancers, product teams, QA teams, and their clients.
- Free plan: yes — 1 project, 3 team members, unlimited guests, 100 MB storage.
- Paid plans: Pro $19/mo ($15.83/mo billed yearly, $190/year) and Team $39/mo ($32.50/mo billed yearly, $390/year). USD.
- Guests: unlimited on every plan, never count against a seat limit, no account required.
- Browser extension: not required.
- Integrations (Team plan): Linear, ClickUp, and Notion turn comments into issues, tasks, or pages with status kept in sync; Slack posts them to a channel; Zapier sends them to other apps. Outgoing webhooks and REST API keys are Team too. No native Jira or GitHub integration yet.
- AI integration: MCP server for Claude, Claude Code, and Cursor on Pro and Team.
- Refunds: 30-day money-back guarantee on all paid plans. Education and nonprofit discounts available via support@huddlekit.com.
- Made by Everace AB, Stockholm, Sweden.

## What distinguishes it
- **Unlimited free guest reviewers on every plan, including the free plan.** Clients comment from a share link without creating an account or installing anything.
- **An MCP server, so an AI coding agent can work the feedback directly.** Connect Claude, Claude Code, or Cursor to a workspace over the Model Context Protocol at https://mcp.huddlekit.com/mcp and an agent reads a comment in full context — the element clicked, the page, the thread, the screenshot — then replies, retags, reassigns, or resolves it while it fixes the code. Read access and write access are granted separately, per person. Requires Pro or Team. Setup: https://huddlekit.com/support/connecting-ai-tools-with-mcp
- **Inspect mode** reads computed CSS on the live page, so a reviewer can check styles without opening DevTools.
- **Canvas view** loads several responsive breakpoints side by side on one URL in a single tab. Pro and Team only; workspace members use it, guests on a share link do not see it.
- **Works on staging, not just live sites**, including applications behind a login.
- **Comments become tasks** on a built-in Kanban board with owners, priorities, and due dates.
- **One workspace for websites and media** — pin comments on pages, and annotate images, PDFs, and video in the same place.

## Markdown access
Every public page on this site has a Markdown representation. Two ways to get it:
- Send `Accept: text/markdown` to any page URL. The response is `text/markdown; charset=utf-8` and carries `Vary: Accept`.
- Or append `.md` to the path — https://huddlekit.com/pricing.md, https://huddlekit.com/blog/best-website-annotation-tools.md, https://huddlekit.com/index.md for the homepage.
HTML responses advertise the Markdown twin in a `Link: <...>; rel="alternate"; type="text/markdown"` header. Markdown responses point back with `Link: <...>; rel="canonical"`.
A request whose `Accept` header rules out both `text/html` and `text/markdown` gets `406 Not Acceptable` with the available types listed, rather than a silent HTML fallback.
Unknown paths return `404` — with a short Markdown body listing where to look instead, when Markdown was requested.
